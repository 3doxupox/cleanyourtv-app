# Upstream examples (commit 69c93b6, v2.4.0) that the app does not ship as profiles, because they
# have no curated entry in profile-meta.json (owner decision D2). The profile build skips exactly
# these folders and fails on any other folder without an entry, and ProfilesTest pins this list to
# the submodule, so a new upstream folder can never slip in silently: give it an entry in
# profile-meta.json, or add it here. A TV that matches none of the shipped profiles still gets its
# brand's sure set or the generic plan.
# Every v2.4.0 folder was reviewed; the folders below were refused, or parked until a contributor
# confirms the match keys, each with the reason after its name.
philips-55pus7503    # refused: same device, firmware and fingerprint as philips-65pus8102, whose list contains every package of this one; the app resolves one profile per TV, so this list could never be picked (contributed by Iago Veiga, PR #209)
portronics-beem-470    # refused: the firmware reports the generic Allwinner ADT-3 identity and the header says to match on a build string; the app matches on brand, model, device, SDK and fingerprint, so a profile would either never match or catch every device with that identity
redmi-mitv-antl0    # refused: Android 5.1.1 (SDK 22). The launcher needs Android 8 (SDK 26), and this firmware refuses pm disable for the shell, the only way the app switches an app off (the list works with pm hide instead)
tcl-43c645    # parked: no device codename or fingerprint in the header, and its model Smart TV Pro names a whole TCL family, so a profile would catch every unknown sibling; ask the contributor for getprop (RF-PROFILES-63 P8)
